# Wi-Fi Connection Troubleshooting

## Problem
The user is unable to connect to the corporate or office Wi-Fi network.

## Category
Network / Wi-Fi

## Issue Type
Incident

## Symptoms
- Wi-Fi does not connect.
- Wi-Fi repeatedly disconnects.
- Internet access is unavailable.
- The corporate Wi-Fi network is not visible.

## Troubleshooting Steps
1. Check whether Wi-Fi is enabled on the computer.
2. Verify that the correct corporate Wi-Fi network is selected.
3. Disconnect from the Wi-Fi network and reconnect.
4. Restart the computer's Wi-Fi connection.
5. Restart the computer if the issue continues.
6. If the corporate Wi-Fi remains unavailable, escalate the incident to Network Support.

## Resolution
For a basic Wi-Fi problem, verify that Wi-Fi is enabled and reconnect to the correct corporate network. If the issue continues after restarting the connection or computer, escalate to Network Support.

## Assignment Group
Network Support

## Priority Guidance
A Wi-Fi issue affecting a single user is normally treated as a medium-impact incident.

## Escalation
If the troubleshooting steps do not resolve the problem, create or update the incident and assign it to Network Support.
