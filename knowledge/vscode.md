# Visual Studio Code Software Request

## Problem

The user wants to install Visual Studio Code on their company computer.

## Category

Software / Software Provisioning

## Request Type

Service Request

## Software

Visual Studio Code

## Request Process

1. Confirm that the user is requesting Visual Studio Code.
2. Check whether the user is eligible to request software.
3. Create a software request.
4. Submit the request for approval if approval is required.
5. After approval, initiate the software provisioning process.
6. Install Visual Studio Code on the user's device.
7. Verify that Visual Studio Code launches successfully.
8. Update the request status after provisioning is completed.

## Provisioning Status

The software request can have the following statuses:

- Requested
- Pending Approval
- Approved
- Provisioning
- Completed
- Failed

## Resolution

Create a software request for Visual Studio Code and submit it through the organization's software provisioning workflow. After approval, provision the software and update the request status.

## Assignment Group

IT Support / Software Provisioning

## Escalation

If approval is required and the request is not approved, do not provision the software. If provisioning fails, escalate the request to IT Support.
