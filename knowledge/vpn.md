# VPN Connection Troubleshooting

## Problem

The user is unable to connect to the corporate VPN.

## Category

Network / VPN

## Issue Type

Incident

## Symptoms

- VPN client fails to connect.
- VPN connection repeatedly disconnects.
- User cannot access internal company resources.
- VPN authentication may fail.

## Troubleshooting Steps

1. Check that the user's internet connection is working.
2. Restart the VPN client.
3. Verify that the user is using the correct VPN credentials.
4. Check whether the VPN service is available.
5. Disconnect and reconnect the VPN.
6. Restart the computer if the VPN client continues to fail.
7. If the issue persists, escalate the incident to the Network Support team.

## Resolution

For a basic VPN connection problem, first verify internet connectivity and restart the VPN client. If the problem continues, verify the VPN credentials and reconnect. Persistent VPN problems should be escalated to Network Support.

## Assignment Group

Network Support

## Priority Guidance

A VPN issue affecting a single user is normally treated as a medium-impact incident. Urgency may be high when the user cannot access required internal resources.

## Escalation

If the troubleshooting steps do not resolve the problem, create or update the incident and assign it to Network Support.
